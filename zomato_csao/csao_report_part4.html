7. LLM-Powered Cold-Start Strategy

Cold-start is a critical challenge for recommendation systems. We leverage text embeddings to handle new users and items effectively.

New Items/Restaurants

  • Use sentence-transformers on item name + description to get semantic vectors
  • Cluster items by semantic similarity to infer "goes-well-with" relationships
  • Fallback to category/cuisine metadata until interaction data arrives

New Users

  • Start with city + cuisine popular add-ons
  • Use segment-based defaults (budget/premium/occasional)
  • Incorporate veg/non-veg preference
  • Mix in diversity for exploration (epsilon-greedy approach)
Example: Text-Based Similarity

For a new item "Chicken Chettinad" with description "Spicy Chettinad chicken", text embeddings identify similar items like "Chilli Chicken" even without interaction history, enabling immediate recommendations.

8. System Design

8.1 Architecture Overview

The CSAO system is designed as a production-ready microservice architecture with clear separation between online and offline components.

Online Layer (Real-Time)
  1. API Gateway: Load balancing, request routing (~10ms)
  2. Feature Fetch: User, restaurant, cart, context from Feature Store (~60ms)
  3. Candidate Generation: ANN search + filtering (~30ms)
  4. Ranking: Hybrid model scoring (~80ms)
  5. Post-Processing: Diversity, business rules (~15ms)
Offline Layer (Batch)
  • Feature Store: Daily batch for heavy features, hourly for fast-changing
  • Model Training: Weekly retraining of GNN embeddings and hybrid ranker
  • ANN Index: Daily rebuild of Faiss/HNSW index for fast retrieval
