1. Executive Summary

This document presents a comprehensive solution for the Cart-Smart Add-On (CSAO) Recommendation System at Zomato. The CSAO system intelligently recommends complementary add-on items to customers based on their current cart composition, contextual factors, and historical behavior patterns.

Key Innovation

Our solution combines Graph Neural Network embeddings for capturing long-term user preferences, session-based modeling for understanding in-session intent, and LLM-powered text embeddings for handling cold-start scenarios. This hybrid approach achieves superior recommendation quality while maintaining sub-300ms latency.

2. Problem Understanding

In the food delivery business, cart value optimization is critical for both customer satisfaction and business profitability. When customers add items to their cart, they often miss discovering complementary items that would enhance their meal experience.

2.1 Objectives

The primary objective is to develop a scalable recommendation system that accurately predicts which add-on items a customer is most likely to add to their cart, given their current cart state and contextual information.

Key Requirements:

  • Real-time predictions: Sub-300ms latency for millions of daily requests
  • Sequential adaptation: Recommendations must update as cart evolves
  • Cold-start handling: Effective recommendations for new users/items
  • Meal completion: Suggest items that complete the meal (main + side + dessert + drink)

3.2 Simulation Logic

The synthetic data reflects real-world patterns:

  • Cities: 7 major Indian cities (Bangalore, Delhi, Mumbai, Hyderabad, Chennai, Pune, Kolkata)
  • User Segments: Budget (50%), Occasional (30%), Premium (20%)
  • Meal Templates: Biryani -> Raita -> Dessert -> Drink, Pizza -> Side -> Drink, etc.
  • Temporal Patterns: Higher order volumes during lunch (11-15h) and dinner (18-22h)
  • Contextual Effects: More beverages in summer/afternoons, more desserts on weekends
Meal Completion Logic

We defined template meals to drive realistic add-on acceptance patterns. For example, a Biryani meal typically includes: Biryani (main) -> Raita/Salan (side) -> Gulab Jamun (dessert) -> Lassi/Soft Drink (beverage).
