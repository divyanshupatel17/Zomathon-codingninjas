5. Problem Formulation

Task Definition

For each cart update, rank candidate add-on items by probability of acceptance (click/add-to-cart) given user $u$, restaurant $r$, cart state $C$, and context $x$:

$$P(accept | u, i, C, x) = f(u, i, C, x; \theta)$$

Problem Type: Ranking problem solved via pointwise classification, with sequential elements since the cart evolves over time.

Labels:

  • 1: Item was shown as CSAO and added to cart (accept)
  • 0: Item was shown as CSAO but ignored (reject)

Two-Stage Architecture:

  1. Candidate Generation: Filter + retrieve ~50-100 candidates using ANN over embeddings
  2. Personalized Ranking: Score and rank top 8-10 items using hybrid model

6. Model Architecture

Our solution follows a baseline to advanced progression, culminating in a hybrid model that combines multiple signals.

6.1 Baseline Models

Popularity Baseline

Recommends top-N popular add-ons per restaurant based on historical attach rate. This provides a strong baseline that captures general item popularity.

Logistic Regression

Pointwise classifier using hand-engineered features (user + item + context + cart aggregates). Provides an interpretable baseline with AUC = 0.769.

Gradient Boosting

Tree-based ensemble capturing non-linear feature interactions. Top features: csao_acceptance_rate (39%), actual_attach_rate (26%), cart_category_diversity (2%).

6.2 Graph Embeddings (GNN)

Inspired by Uber Eats and Swiggy's use of Graph Neural Networks, we build a heterogeneous graph:

  • Nodes: Users (5,000), Items (7,914), Restaurants (800)
  • Edges: User-Item (orders), Item-Restaurant (menu), User-Restaurant (sessions)

The graph embeddings capture collaborative filtering signals and enable similarity-based recommendations:

  • sim(user, item): User preference for item
  • sim(cart, item): Cart intent similarity
  • sim(restaurant, item): Restaurant-item affinity

6.3 Session-Based Model

We use a VMIS-kNN (Vector Space Model for Item Selection with k-Nearest Neighbors) approach for session-based recommendations:

  • Represents each session as a sequence of item interactions
  • Finds similar sessions based on cart composition
  • Recommends items that were added in similar sessions
  • Achieves P90 latencies of a few milliseconds at scale

6.4 Hybrid Ranker

The final model combines all signals:

Hybrid Model Architecture
  • Graph Embeddings (16-dim each): User, Item, Restaurant embeddings
  • Similarity Features: user_item_sim, rest_item_sim
  • Context Features: Cart aggregates, temporal, device
  • Raw Features: Price, margins, user segment, time-of-day
  • Ranker: Gradient Boosting with 150 trees, max_depth=5
