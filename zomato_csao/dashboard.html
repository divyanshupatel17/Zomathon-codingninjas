System Pipeline
Real-Time Inference Pipeline
End-to-end latency breakdown — P95 total: 41ms (well within 200ms SLA)
Architecture
Step 1 — ~2ms
Cart Trigger
Item added/removed event triggers CSAO recommendation update via API
Step 2 — ~8ms
Feature Fetch
User, restaurant, and temporal features retrieved from Redis cache
Step 3 — ~5ms
Candidate Gen
Rule-based filter narrows candidate pool from 7,914 to 50-100 items
Step 4 — ~18ms
LightGBM Score
Model scores all candidates; top-10 selected by acceptance probability
Step 5 — ~8ms
Response
Ranked JSON payload returned to frontend; CSAO rail rendered
